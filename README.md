# Persona 5 Portfolio Starter

A React + Vite starter for a Persona 5 Royal-inspired personal site.

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - type-check and build
- `npm run preview` - preview production build

## New UX features

- Persona-like route transition overlays between sections.
- Top-left date + climate HUD (defaults to Buenos Aires using Open-Meteo).
- Route-based background image slots (`home/about/resume/projects/experience/contact`).

## Music slider

The footer includes a mini music control widget (play/pause, next track, and volume slider).

Drop your music files in:

- `public/media/audio/track-1.mp3`
- `public/media/audio/track-2.mp3`

If these files are missing, the UI still renders but no track will play.

## Background assets

Place your backgrounds here:

- `public/assets/backgrounds/home.webp`
- `public/assets/backgrounds/about.webp`
- `public/assets/backgrounds/resume.webp`
- `public/assets/backgrounds/projects.webp`
- `public/assets/backgrounds/experience.webp`
- `public/assets/backgrounds/contact.webp`
